# Data and code availability

The source calibration data are available from Qiskit Calibration Drift at
https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift.
The original fifteen-circuit study's code, selected calibration records,
circuit definitions, configurations, seeds, native executables, simulated
output distributions, baseline comparisons, timing records and reproduction
scripts are available in release v1.0.0:
https://github.com/mskrcnis/response-guided-qubit-placement/releases/tag/v1.0.0.

Additional validation materials are deposited separately in release v1.1.0:
https://github.com/mskrcnis/response-guided-qubit-placement/releases/tag/v1.1.0.
They include exhaustive candidate-level scoring and search results,
coefficient-reuse measurements, matched-time comparisons, additional circuit
and physical-region inputs, noise-model sensitivity results, documented
failures and unavailable conditions, and scripts reproducing the validation
tables and figures. Frozen protocols, source revisions, calibration timestamps,
seed specifications, environment records and SHA-256 checksums support traceability.
The original release is preserved, and the additional deposit does not imply
that the manuscript has incorporated the new findings.

The deposited outcomes are simulations using recorded calibration properties,
not new physical-device execution measurements. Original code is MIT; original
research outputs and upstream calibration-derived data are CC BY 4.0 with
attribution. Third-party code retains its own terms. No DOI is asserted.

# Data and code availability

The code and data supporting this study are available in the
response-guided-qubit-placement repository at
https://github.com/mskrcnis/response-guided-qubit-placement, release v1.0.0
(https://github.com/mskrcnis/response-guided-qubit-placement/releases/tag/v1.0.0).
The release provides the compilation and evaluation code, circuit inputs,
selected calibration records, simulated output distributions, numerical
results, provenance manifests, and scripts for reproducing the analyses,
tables and figures. Original code is distributed under the MIT license.
Calibration data are derived from the publicly available Qiskit Calibration
Drift dataset (https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift)
under CC BY 4.0, with source revisions and checksums recorded in the repository.
Third-party compiler implementations are obtained from their original sources
at the recorded versions and retain their respective terms.

The release contains simulated experimental outputs; it does not contain new
physical-device execution data. A GitHub release URL is supplied here; no DOI
or independent archival deposit is claimed.

# Data and code availability

The source calibration data are available from Qiskit Calibration Drift at https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift.

The complete code and data for the original study and additional validation are provided together in **release v1.2.0** at https://github.com/mskrcnis/response-guided-qubit-placement/releases/tag/v1.2.0. Download `qst-data-code-v1.2.0.zip`. It contains original circuit definitions, selected calibration records, native executables, output distributions, baseline comparisons, timing records, all additional validation data, and scripts reproducing both analyses. Original and validation cohorts/protocols remain distinct within the same archive. No downloads from older releases are required for the saved-data analyses.

Frozen protocols, calibration timestamps, source revisions, seeds, environment records and SHA-256 checksums support traceability. The outputs are simulations using recorded calibration properties, not new physical-device execution measurements. Original code is MIT; original research outputs and upstream calibration-derived data are CC BY 4.0 with attribution. Third-party software retains its own terms. No DOI is asserted.

Comparison scope and fairness:
Same raw circuits, 6-qubit patch, directed CZ edges, CZ/RZ/SX/X native basis, eligible dates and output definitions. Baselines retain their own objectives. Default heuristic QMAP, default depth-4 DFS Duostra, author SQGM decay with enhanced heuristic and 3-iteration SabreLayout; LightSABRE 20 layout and 20 swap trials, 3 iterations; Mapomatic unmodified default success-product scoring after that LightSABRE pipeline. Common zero-optimization CX/1Q lowering before baselines, terminal-measurement barrier, common native CZ lowering optimization_level=1 after routing. Existing swarm native outputs unchanged.
Native-configuration comparison, not equal runtime or equal candidate work. Swarm has 56 unique placements. LightSABRE has 20 layout and 20 routing trials per configured layout. Mapomatic enumerates valid post-routing embeddings; QMAP/Duostra native search. No winner chosen with noisy evaluation TVD.
QMAP and Duostra ignore external seeds; compile once per circuit. Reused deterministic outputs and repeated static calibration states are not independent trials.
Equal date/circuit/replicate/seed-rule weight within each predefined stratum. Paired differences, per-circuit and per-date means, seed-rule and changing-calibration sensitivity, leave-one-date-out range. No IID p-values or statistically significant superiority claim from correlated technical cases.

Published provenance:
mapomatic: Suppressing Quantum Circuit Errors Due to System Variability; PRX Quantum (2023). https://doi.org/10.1103/PRXQuantum.4.010327. 
sqgm: Single-Qubit Gates Matter for Optimising Quantum Circuit Depth in Qubit Mapping; ICCAD (2023). https://doi.org/10.1109/ICCAD57390.2023.10323863. 
duostra: Robust Qubit Mapping Algorithm via Double-Source Optimal Routing on Large Quantum Circuits; ACM Transactions on Quantum Computing (2024). https://doi.org/10.1145/3680291. 
qmap: MQT QMAP: Efficient Quantum Circuit Mapping; ISPD (2023). https://doi.org/10.1145/3569052.3578928. Tool paper 2023; underlying default heuristic originates in Zulehner et al., IEEE TCAD 2019. Not a newly invented 2023 heuristic.
lightsabre: LightSABRE: A Lightweight and Enhanced SABRE Algorithm; arXiv preprint; peer-reviewed venue not verified (2024). https://doi.org/10.48550/arXiv.2409.08368. Current Qiskit 2.5.2 implementation; paper benchmarks Qiskit 1.2.0. Not exact paper-version reproduction.

The common circuit adapter is not an exact reproduction of each paper's original end-to-end benchmark. Maintained implementations, versions and all deviations are pinned in the protocol.
Mapomatic sees only eligible calibration parameters and uses its published default success-product objective. No method sees evaluated noisy TVD during selection.
Duostra uses abstract unit gate durations, not measured device pulse times. Rational-pi interchange avoids the upstream decimal parser's 1e-4-radian quantization. Its routing algorithm is unmodified; the source patch adds permutation logging and build compatibility only.
The noise model omits idle relaxation, crosstalk, leakage and calibration uncertainty. Small-circuit in-model comparisons do not establish large-circuit or physical-device superiority.
These are per-date compilation comparisons, not a test of an ML decision about when to recompile. No pre-search controller is qualified.

Validation: 2494 arbitrary-input measurement checks; 2780 independent noisy-channel evaluations. Maximum discrepancies: 7.14e-13 (measurement semantics), 6.53e-13 (noisy probabilities).
Compilation timing from the main run is concurrent and diagnostic only. Consult separate serial timing results when present.
